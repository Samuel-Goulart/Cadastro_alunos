# Sistema de Cadastro de Alunos

Aplicação desenvolvida em C# com foco no gerenciamento e cadastro de registros de alunos, praticando conceitos fundamentais de programação orientada a objetos e manipulação de dados.

## ✨ Funcionalidades
- Cadastro de novos alunos
- Consulta e listagem de registros
- Atualização e remoção de dados

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** C#
- **Plataforma:** .NET
